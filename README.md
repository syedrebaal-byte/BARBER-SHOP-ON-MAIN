# Barber Shop On Main 💈

Clean, modern, and minimal Bento website for **Barber Shop On Main** located in Downtown San Antonio, TX.

- **Facebook:** [Barber Shop on Main](https://www.facebook.com/p/Barber-Shop-on-Main-100077086531959/)

## ✨ Key Features
- **Folder-less Architecture:** Flat structure where all files and images are in the root directory for guaranteed 100% Vercel & GitHub compatibility with zero path errors.
- **Minimal Bento Design:** High-contrast frame layout with yellow highlight on the Most Requested Deal.
- **Interactive Scissor Cursor:** Click-to-snip with falling hair particle physics.
- **Continuous Animations:** Infinite marquee and rotating 3D barber pole.
- **Live Open/Closed Status:** Automatic Central Time (San Antonio) status calculator.

## 📁 Repository Structure (100% Flat / Folder-less)

## 🚀 Deploy to Vercel
1. Push this folder to your GitHub repo.
2. Import repo on [vercel.com](https://vercel.com).
3. Click **Deploy** (Zero-configuration required).
