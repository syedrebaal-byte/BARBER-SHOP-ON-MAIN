## ✨ Key Features
- **Modern Minimalist Bento Grid Architecture:** Inspired by high-contrast brutalist design with rounded pill badges, crisp typography, and visual hierarchy.
- **Interactive Scissor Cursor:** Dynamic scissors cursor following pointer movement with blade snip animations, Web Audio synthesized snip acoustics, and falling hair strand particles on click.
- **Continuous Animations:** Infinite marquee ticker, 3D animated barber pole, pulsing live open/close status indicator calculated in real-time according to Central Time (San Antonio).
- **Service & Transparent Pricing Menu:** Interactive cards with one-click direct appointment call prompts.
- **Authentic Google Reviews Wall:** Real reviews from local guides and customers with interactive category filters.
- **Zero-Dependency Static Build:** Ready for 1-click deployment on Vercel via GitHub or any static host.

## 🚀 Deploying to Vercel

### Option 1: Via GitHub & Vercel Dashboard (Recommended)
1. Push this repository to your GitHub account:
   ```bash
   git init
   git add .
   git commit -m "Initial commit for Barber Shop On Main"
   git remote add origin https://github.com/YOUR_USERNAME/barber-shop-on-main.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import the GitHub repository.
4. Keep the default settings (Framework preset: `Other`) and click **Deploy**.

### Option 2: Via Vercel CLI
```bash
npx vercel
```
